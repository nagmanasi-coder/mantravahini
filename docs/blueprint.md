# **App Name**: ಮಂತ್ರವಾಹಿನಿ (Mantravaahini)

## Core Features:

- Mantra Playback: Play pre-loaded mantra MP3 tracks. The player supports standard controls like play, pause, and next.
- Track Switching: Enable users to switch seamlessly between different mantra tracks using a list-based interface.
- AdMob Integration: Display banner and interstitial ads using Google AdMob or a similar ad network to monetize the app.
- Smooth Playback Across Devices: Ensure consistent and smooth playback across different browsers, operating systems, and devices.
- Kannada Language Support: Ensure the app's user interface displays all text in the Kannada language for better accessibility and user experience.

## Style Guidelines:

- Primary color: Deep saffron (#FF7F50) to reflect spiritual warmth.
- Background color: Soft beige (#F5F5DC) to provide a calm, neutral base.
- Accent color: Muted gold (#DAA520) to highlight interactive elements subtly.
- Body and headline font: 'Literata', a serif font to enhance readability of Kannada text, and evoke a literary feel.
- Use simple, intuitive icons for playback controls and navigation.
- Maintain a clean, list-based layout for track selection to ensure easy navigation.
